# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Do not commit patient data, ultrasound recordings, credentials, device serial numbers,
   proprietary SDK files, vendor examples, generated build outputs, or machine-specific paths.
2. Keep rotational and linear motion interfaces separate and preserve the documented ROS 2
   topic units unless the change is explicitly discussed.
3. Describe the hardware and software versions used for validation.
4. Run the syntax, patch, and ROS 2 build checks described in the README before submitting.
5. Confirm that you have the right to submit the contribution under the repository's
   Academic Research License.

Unless explicitly stated otherwise, intentionally submitted contributions are licensed under
the PNU Advanced Robotics Lab Academic Research License 1.0 described in `LICENSE`.
